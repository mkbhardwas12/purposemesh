# Changelog

Notable changes to Contract Capsule Authorization are documented here. The
project follows semantic versioning once a stable public API is declared.

## [Unreleased]

- First public-repository publication and connector pilot feedback.

## [0.1.0] — 2026-08-16

- Added the working React, Fastify, CCA core, and SQLite reference path.
- Tested authorization behavior with a deterministic 100,000-record synthetic
  dataset across four modeled pipeline families.
- Added purpose-bound row and field enforcement, AuthZEN evaluation, dual role
  approval, separation-of-duty checks, JIT access, assignment-bound
  recertification, offboarding, compiler previews, and recovery tooling.
- Added 194 automated core, API, and web checks plus production builds and
  dependency audits.
- Published the architecture, security model, complete HTML brief, and verified
  executive/developer presentation.
