## [0.1.0] — Technical Preview — 2026-08-16

- Renamed the public project to PurposeMesh: Purpose-bound access, enforced everywhere.
- Marked the project as a Technical Preview and documented how it complements
  proven identity, policy-decision, relationship, and native-enforcement systems.
- Added an evidence-gated public roadmap for real adapters, interoperability,
  operational hardening, and stable-release criteria.
- Added a reproducible, hardened Docker Compose demo and technical-preview release
  automation that generates an SBOM and checksums.
- Refreshed the social preview and test evidence for 196 automated checks.
- Added the working React, Fastify, PurposeMesh policy core, and SQLite reference path.
- Tested authorization behavior with a deterministic 100,000-record synthetic
  dataset across four modeled pipeline families.
- Added purpose-bound row and field enforcement, AuthZEN evaluation, dual role
  approval, separation-of-duty checks, JIT access, assignment-bound
  recertification, offboarding, compiler previews, and recovery tooling.
- Added 196 automated core, API, and web checks plus production builds and
  dependency audits.
- Published the architecture, security model, complete HTML brief, and verified
  executive/developer presentation.
